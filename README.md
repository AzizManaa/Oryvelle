# Oryvelle

Public web project for Oryvelle.

## Public policy content

The authoritative privacy wording is maintained in the Android repository at
`doc/PRIVACY_POLICY.md`. Keep `app/privacy/page.tsx` synchronized with that
document and publish the website whenever the policy changes. The public Terms
and Support pages must likewise stay aligned with `doc/TERMS_OF_SERVICE.md` and
`doc/SUPPORT.md` in that repository.
